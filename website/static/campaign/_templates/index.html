Never include

  • B2B, shops, schools, media. Retailers and journalists, not riders.
  • SUP, kite and windsurf-only lists. Wrong sport, earns unsubscribes.
  • TG ALL, xmas resends, Trickgenius. 2015 to 2019 and cross-sport. Bounces land on the same domain as your order confirmations and the Q&A reminders.
  • Anything named subtract, not opened, EXCLUDE, bounced or testlist. Campaign artefacts, not audiences.

Already covered, do not add

The 43 people on the Q&A list itself live in the coaching database, not Sendy, and they already get the invite automatically 7 days before every session. Putting them in Sendy would mail them twice.

11 of them happen to also be shop customers, so they will see both this time. That is the only overlap and it is small enough to leave alone.

This definition lives in backend-php/api/cron/qa-promo-audience.mjs. Run node qa-promo-audience.mjs before a send and it re-reads the live sizes and prints the list ids to paste.

What to reuse next month

Never changes. Set once, leave alone.

  • The Zoom room. Same link every month, already on every session through December.
  • The comment keyword "QA" on all three accounts. It registers people into whichever session is next, so it never needs re-pointing.
  • The signup link ?signup=next. Always resolves to the next session.
  • The reminder chain, the invite, the replay email. All automatic and stamped.
  • The layout of these graphics: grey header, blue rule, photo, footer band.
