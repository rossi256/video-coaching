What changed today

All four are live on production and verified in a browser, not just in code.

  • "Save my spot" is genuinely one click The invite button now carries a signed token tied to that person's address. Clicking it registers them and shows "Michi, you're in!" straight away. No name, no email, no form. A stale or broken token falls back to the normal signup form with a plain explanation instead of hanging.
  • The confirmation email finally carries the Zoom link It used to live only inside the calendar attachment, so anyone who did not import the .ics had no clickable link until the first reminder fired. The link is the same recurring room every month, so it is safe to keep.
  • Times are labelled CEST Confirmations and reminders said "7:00 PM" with no timezone. A third of the list is outside continental Europe (Canada, UK, Poland, Bulgaria, Sweden).
  • The camp-page opt-in reaches the invite list Plus the five people it had already dropped, now added and invited.

Two things still open

Worth a decision

There is no unsubscribe link. The invite says "reply no more and I will take you off", which means a human has to read it and set a flag by hand. The database column exists and the sending code already respects it. With the list at 44 this is fine. It stops being fine at a few hundred.

Worth a decision

Q&A emails do not copy you. Your rule is that every automated customer-facing email BCCs rossi@tricktionary.com. The Q&A confirmations, reminders, invites and replay emails do not. You only see the separate admin notification, which does not show what the person actually received.
